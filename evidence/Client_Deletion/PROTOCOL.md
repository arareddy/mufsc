## Candidate invariant and scope

For the active set of original client IDs, each nonempty (c,g) summary is byte-identical to fresh local seeding on that unchanged slice with its original keyed tape. Each client holds two integer counts derived from the already produced canonical summary n_e; their sums equal global n_0,n_1. Empty clients have (0,0). Whole-client deletion removes all and only those summaries, subtracts exactly those counts, and rejects any request that leaves a required global group empty. Rebuild canonical anchors and exact h/n_g weights and run the canonical server anew with the same seed. No stale centers, frozen weights or unchanged-server shortcut. Local raw data, labels, coordinate matrices and per-row deletion masks are absent from the fast request API. Preparation copies and checks compact summaries once; counts come from existing local summary metadata without a new raw-record scan.

Unchanged survivor slices plus identical global counts imply identical ordered server input, random tape and indexed C0. At T=0 the trajectory is [C0] and the N/S/SS list is empty. The proof also supports a valid finite whole-client sequence by induction on active clients. This is a deterministic model-projection equality claim for the declared map and trusted internal state. It is not an erasure claim, a deployment privacy guarantee, an adaptive independent-randomness statement or equality of all fresh/replay caches. Initial checkpoints, immutable datasets, previous in-memory states and experimental outputs can retain deleted personal information. No secure deletion is attempted.

Canonical fresh may omit the empty departed client dictionary entry; direct replay leaves an empty entry. Neither changes surviving IDs, slices, ordered anchors or model. Extra compared state is exactly group_sizes, every surviving slice summary (including selected indices/reps/multiplicities) and ordered anchor table with rational weights. Fresh raw/encoded arrays and replay caches are not claimed equal. The compact state can be advanced; it is not accepted by the original unlearn API.
