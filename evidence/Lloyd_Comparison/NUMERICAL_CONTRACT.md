# Numerical contract and verification scope

## Controlled difference

Both trajectories use the same retained represented X=m/4096, group labels, persistent ownership, row order, indexed initial binary64 centers and assignments. Fixed clips are 175/121/74. The canonical fair trajectory is newly run from raw saved retained arrays through train_full(T=2,L=6,gamma=0,anchor_lloyd_iters=0,build_cache=False); all its C0..C2 and exact N/S/SS match the saved source witnesses before Lloyd is evaluated.

The separate Lloyd update uses cluster population count N_j=sum_g N_gj and coordinate sum S_j=sum_g S_gj. Every occupied coordinate is float(Fraction(S_j,4096*N_j)), with no group-size normalization. This is ordinary unweighted clustering over records. An empty cluster retains its old indexed coordinate exactly. No worst-group or SSE acceptance guard is applied. It shares production exact indexed assignment and integer-statistics kernels to isolate update choice. The next round assigns records against the newly represented centers; quality scoring also reassigns, rather than reusing the update partition.

Fair's rational group-weighted candidate and Lloyd's rational population mean both become binary64 once per update. Neither is snapped to the original input grid. This representational convention differs from an implementation that sums floats or re-encodes centers; such implementations are not the comparator here. Exact real centroids need not be representable. Conditional on correctly rounded nearest binary64 conversion, a rounded mean minimizes the separable fixed-assignment quadratic over finite binary64 coordinates, so retaining the same representation for old/new centers supports SSE nonincrease before reassignment. This reasoning is not a proof of the entire software/runtime, an exact-real centroid claim, or a global/convergence guarantee. We report the actual exact observed SSE inequalities (all 60 Lloyd adjacent steps decrease) and explicitly test thirds and midpoint ties.

## Independently recomputed nearest-center scoring

scoring.py imports no canonical code. For each coordinate difference z=fl(x-c), nextafter(z,-inf/+inf) encloses the exact difference. The squared interval uses the smallest/largest possible absolute endpoint, zero if the interval crosses zero, and outward nextafter around each endpoint multiplication. Under IEEE round-to-nearest with gradual underflow and no overflow, these enclose the exact coordinate square. Summing nonnegative lower/upper bounds uses a conservative gamma=d*epsilon/(1-d*epsilon), with epsilon=2^-52; multiplying the lower sum by 1-gamma and dividing the upper sum by 1-gamma, then nextafter outward, bounds reduction error. The doubled unit-roundoff bound covers the finite dimensions and rounding of these factors used here; scalar fixtures check exact values in this execution domain. The implementation rejects nonfinite intervals.

Take the candidate with smallest upper bound. Only centers whose lower bound is at most that upper bound can beat or tie it. A unique candidate is certified; multiple candidates are compared using a separately written scalar Fraction squared-distance sum, with smallest-index ties. Fixtures explicitly cover ambiguous ties/duplicate centers. No full-dataset row was ambiguous in this grid, and each full label array agrees with the canonical certified-assignment implementation.

On those independently selected labels, the scorer builds its own count/sum/squared-sum reductions from represented integer coordinates. Before using int64 vector reduction it checks n*d*M^2<2^63 and n*M<2^63 using Python integers, where M is the largest absolute encoded coordinate. This bounds products and all sum intermediates, including signed coordinate sums. Group cost expands the exact represented-center squared distance with Fraction arithmetic; no rounded summary enters arithmetic. The scalar fixture oracle instead sums exact pointwise nearest-center squared distances, separately from moment expansion.

Each of the 150 distinct evaluated center tuples is newly scored from X, its independently determined labels are compared to the canonical full label vector, and its Phi_0/Phi_1/G/Phi fractions are compared to canonical fair_objective. All 90 fair tuples are also checked against saved exact objectives. T0 is evaluated once per case, then duplicated only for method presentation. Case outputs include exact center bytes/hex coordinates, raw integer N/S/SS, exact objective fractions, independent label hashes and input/source/retained-identity bindings.

The numerical runtime is shared Python/NumPy; the independent scorer and scalar fixture oracle are separately written code, not an independently authored human audit. Canonical assignment, train and fair-update arithmetic guarantees and prior oracle gates remain inherited. The new checks specifically reproduce saved fair evidence, exercise the additive Lloyd implementation, and recompute its quality independently.

## Fixed fixtures and limits

Five scalar fixtures: unequal 3:1 groups with k=1 (Lloyd center2.5 vs fair center5, making the genuine SSE/Phi tradeoff exact); indexed assignment ties with an empty center; duplicate centers; inexact rational thirds; a two-dimensional case with an empty center. Each has two Lloyd updates checked against a scalar exact-mean oracle and all three budgets scored against direct pointwise rational distances. Two further aggregate-only fixtures produce exactly halfway means 1+2^-53 and 1+3*2^-53, checking ties-to-even expected hex values. These aggregate fixtures are not raw training datasets. No new parameter tuning or fairness threshold follows from them.

Group means use positive retained n_g. Phi=max group means, G=sum group means, SSE=count-weighted sum, population-average=SSE/n. Seed averages of Phi apply max before averaging. Pairwise relative differences use the corresponding Lloyd metric as denominator; within-method changes use that method's earlier budget. A zero denominator is explicitly undefined in the aggregation code; all observed denominators are positive. Sample SD uses n-1 for five seeds. No confidence interval, significance test, timing-repeat inflation, model-adaptive guarantee, cache equality, erasure or Lloyd unlearning claim.
