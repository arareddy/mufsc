Status: implementation contract, subject to independent gate. This changes seeded outputs from both frozen snapshots. There is one canonical kernel in corrected_project/src, based on P124 (merged gamma support and server delta timers), with P3 drivers/tests ported to it. Historical measurements remain separate.

## Fixed dataset and numeric domain
Preprocessing (vocabulary, imputation, scaling, population selection) is fixed before this map. Its deleted-record influence is outside the guarantee. Encode each input binary64 x once as m=roundTiesToEven(clip(x,-clip,clip)*2^b); X=m/2^b is the sole represented dataset for both initialization, refinement and quality. Finite binary64 input with magnitude at most 2^450, rectangular feature dimension in 1..4096, group IDs 0/1, stable nonnegative integer client IDs, both global groups nonempty. b is integer 0..30, positive finite clip with clip*2^b <=2^52. Reject numeric configurations unless d*M^2 <=2^59 (M=rounded clip*2^b), before squaring/casting. Actual accumulator input must be int64, valid labels/groups, and obey the same per-point bound; chunks have sum bound 2^59 and totals use Python integers. No silent overflow or saturation of integers. Empty clients preserve dimension and identity.

## Randomness and ordinary two-level seeding
Ordinary k-means++ within each nonempty (client,group) slice; weights 1 initially and exact squared distances thereafter. Local multiplicities assign to indexed unsnapped representatives. Server anchors ordered lexicographically (client,group,slot), with exact rational mass h/n_g, never rounded h/n_g. Baselines likewise use exact rational local/global normalized weights. Rational mass vector is cleared to nonnegative integers by lcm of denominators then gcd of numerators. Draw U uniformly in [0,W) by rejection of b=bit_length(W-1) independent bits; W=1 consumes no bits. Candidate bits use ceil(b/64) 64-bit words, first word least significant, mask off bits >=b, discard unused bits; redraw all words on rejection. W=0 is deterministic completion, no draw.

Under ideal independent fair bits each accepted integer has probability 1/W: in a trial it has probability 2^-b, acceptance W/2^b, and the geometric sum gives 1/W. Every positive integer category receives its exact count/W; zero categories never sampled. This mathematical statement is separate from finite deterministic PRNG runs. Execution uses explicit NumPy PCG64(SeedSequence([seed,role_id,*entity_ids])); roles local=1, server=2, merged_local=3, merged_server=4, centralized=5. Nonnegative integer entropy only. Freeze NumPy/environment for reproducibility. No assertion of mathematical stream independence or ideal randomness for a finite PRNG.

For k>=n, return ascending input indices and cyclic duplicates until k, consuming no bits (local budget min(k,n)). Otherwise start with weighted draw, then D^2 draws. On zero total mass, append remaining unselected indices ascending, then cyclic 0..n-1; this includes zero-weight rows. Empty n permits k=0 only. Zero k returns empty. Coincident locations retain distinct IDs.

## Represented centers, assignments, quantization, fair update
Center arrays are indexed finite binary64 values, interpreted as their exact dyadic rationals. Exact squared Euclidean comparisons choose smallest center index; runner-up is second in the order (distance,index), including coincident centers. The binary64 filter computes s=sum(fl(x-c)^2), g=(d+8)*2^-52 and tau=min_subnormal, enclosing the exact squared norm by outward-rounded [(s-d*tau)/(1+g),(s+d*tau)/(1-g)], lower-clamped at zero; identical vectors have exact [0,0]. This bound assumes IEEE round-to-nearest binary64, no flush-to-zero, and the validated geometry range. Fast floating intervals may decide disjoint bounds; overlapping bounds fall back to exact dyadic rational/integer comparisons. No tolerance/permutation equality.

Gamma=0 leaves representatives unchanged. Gamma>0 denotes its actual binary64 rational; snap each coordinate by exact nearest-integer ties-even on x/gamma then multiply by rational gamma and round once to binary64. Thus rounding to represented output is included in quantization residuals; ideal d*gamma^2/4 bounds require this representational qualification or the actual measured Q. Gamma cannot change payload bytes for a float64 coordinate array.

For each fixed partition derive exact N,S,SS on encoded integers. Evaluate any represented C exactly using f_g(C)=[sum_j SS_gj/scale^2 - 2<C_j,S_gj>/scale + N_gj||C_j||^2]/n_g. Candidate lambda endpoints 0,1 plus L rational dyadic bisection points. Use exact rational means S/(N*scale) and group-cell weights N/n_g. With both groups present in a cell, candidate is (lambda*alpha*mu_A+(1-lambda)*beta*mu_B)/(lambda*alpha+(1-lambda)*beta), rounded once per coordinate to binary64. One-group cell uses that group's mean for all lambdas, including zero-weight endpoint. Both-empty cell retains incumbent. Bisection takes lower=lambda iff actual represented candidate f_A>f_B; equality takes upper=lambda. Choose minimum exact max(f_A,f_B), smallest rational lambda on ties; accept iff its cost <= incumbent exact cost. k positive; T,L,anchor-Lloyd counts nonnegative integers (L<=256). Optional anchor Lloyd uses exact weighted means with one final binary64 rounding and exact represented weighted-objective guard.

## Certificates, fallback, replay and output
Cache stores indexed labels/runner-up and outward lower/upper Euclidean distance bounds. Center shifts also have outward bounds. Basic upper winner is upper(d1)+upper(shift_j); competitor lower is max(0,lower(d2)-max_other upper(shift)). Runner-up uses interval distance between [lower(d2),upper(d2)] and [lower(shift_r),upper(shift_r)], intersected with other-competitor lower. Only strict upper<lower certifies. For k=1 assignment is always index0. Any inconclusive bound triggers exact/certified nearest assignment. Bounds never turn underflow into an exact zero shift. All top-shift order/exclusion uses indices. Full sorting costs are charged.

Replay regenerates touched slices with same keys, reuses untouched slices, reruns server with survivor group normalization. Subtract deleted old-label statistics, patch failing survivors, and apply same GFU. If failed fraction strictly exceeds the actual represented threshold (default 1/2), compared by integer cross multiplication, discard current patches, rebuild entire current round and all later rounds; count failed assignments already computed as sunk/duplicated J. Exactness compares indexed C0..CT and raw N/S/SS, not shared digest flags. Train may produce full cache; replay produces trajectory/final model with cache_valid=false and cannot itself be replayed. Optional fresh model-only output skips cache construction while preserving same trajectory/statistics for fair timing.

Deletion identity is (checkpoint client ID, original local row index), resolved to source IDs by driver manifest. Finite nonnegative thresholds are accepted; thresholds >=1 disable abandonment, preserving the prior test/API convention. Reject unknown clients, nonintegral/negative/out-of-range indices, duplicates, invalid modes/thresholds, and any request emptying either global group. Sort valid request indices; preserve client IDs and survivor order. Requests are independent against original checkpoint; no sequential cache service is claimed.

## Evidence and costs
N=all survivor point-rounds; A=attempted certification point-rounds; P=passing attempted point-rounds; S=passes in nonabandoned rounds that save final assignments; J=failed assignments repeated at current-round fallback. Report P/A and S/N with denominators, seed means separately from pooled fractions.
