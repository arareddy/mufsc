# Public supplementary release

This repository distributes only the supplementary material for *Machine Unlearning for Federated Socially Fair k-Means Clustering*. The manuscript PDF, bibliography, LaTeX styles and complete manuscript source are reserved for arXiv and are not included here.

The supplement derives from the final ICLR review archive, SHA-256 `cb3982e2db3d3525637d50495667814fbe9236cacebcf159e22eb4581934b995`. Public packaging restores the original identifying MIT notice, adds attribution and navigation, and regenerates the root release manifests. Scientific code, processed datasets, saved results and the five Lean bundles retain their review-release bytes. Historical receipts certify only the runs and sources they identify.

The release ZIP includes processed data arrays excluded from Git. Supplementary plot PDFs and standalone generated table fragments remain as experimental evidence; they are not a manuscript source package.

Packaging correction, October 9, 2026: manuscript sources were briefly included by mistake and were removed from the repository's current contents and release assets. The correction does not change the scientific implementation or evidence.

Verification scope: file hashes and all 11 processed datasets were checked, and saved-evidence aggregation passed. Packaging does not constitute a fresh full experimental campaign or a new Lean compilation.
