# Packaging adaptations

No numerical implementation in the frozen scientific-source manifest was edited. The package adds orchestration and storage adapters:

1. `reproduce.py` loads safe NPZ arrays and dispatches explicit configs to unchanged kernels; P4's dataset loader is injected with these exact arrays. P1/P4 import their own historical source in fresh processes.
2. Original user paths and identifying references are redacted in evidence/reference orchestration. Reference scripts retain symbolic provenance paths and are inspection material. Portable commands are only the root-level programs documented in README.
3. `validation/oracle` changes `corrected_project` import paths to `core`. The original pickle-loader tests and old-descriptor-comparison tests are not part of the portable 193-test count: their legacy pickle/old-source inputs are absent. Instead `verify` checks all packaged arrays and immutable source hashes. The original historical 213-test result remains historical evidence, not a new result.
4. `validation/client` adapts source roots and removes snapshot-specific import-time checks from the candidate review wrapper. The portable runner invokes scalar grid, invalid requests, raw-access traps and alias-scope checks directly. The old request-wrapper-boundary function is retained for inspection but not invoked. Numerical oracle functions are preserved.
5. `variants/multigroup/common.py` changes source-root lookup and retains only serialization helpers needed by the unchanged numerical module/oracle. Original full multi-group tests run with output/hash paths injected by the portable runner.
6. `timing_adapters` extracts the original measured functions without editing their bodies. P3's worker changes import paths only; the caller supplies a new explicitly labeled runtime gate only after the portable fixture suite passes. The historical source gate remains unchanged. The diversity orchestration uses the original C0 request function; its per-case setup difference is documented.
7. `plotting` adapts input/output roots and removes machine-specific render commands. Newer-study plot mathematics, labels and CSV values are retained. Four original figures are separately replotted from the same saved CSV quantities using a portable plotting style. PDF container metadata is stripped in the saved `figures/` copy; page content and extracted text were verified unchanged.
8. `raw_acs.py` adapts source acquisition/output locations and invokes the original `build_pool` and federation helpers. It verifies source hashes and rebuilt array hashes. Fresh metadata hashes are not historical provenance; original environment/source manifests remain available.

`verify_tables.py` is a separate exact-Fraction reaggregation of quality identities, means/variances and paired Lloyd differences. It does not train models. Timing summaries are never interpreted as independent statistical trials merely because several budgets or timing repetitions exist.
